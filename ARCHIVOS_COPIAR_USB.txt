════════════════════════════════════════════════════════════════
  🚀 CÓMO USAR LOS ARCHIVOS EN LINUX MINT
════════════════════════════════════════════════════════════════

PASO 1: Copiar archivos al servidor
------------------------------------
1. Conecta el USB al servidor Linux Mint
2. Copia los archivos al sistema:

   sudo cp -r /media/[usuario]/[nombre-usb]/sistemaEstacionamiento/tests \
              /var/www/html/sistemaEstacionamiento/

   sudo cp -r /media/[usuario]/[nombre-usb]/sistemaEstacionamiento/scripts \
              /var/www/html/sistemaEstacionamiento/

3. Dar permisos de ejecución al script:

   sudo chmod +x /var/www/html/sistemaEstacionamiento/scripts/instalar_gd_linux.sh

PASO 2: Diagnóstico inicial
-----------------------------
cd /var/www/html/sistemaEstacionamiento
php tests/test_gd_logo.php

Esto te dirá QUÉ falta (GD, formato, etc.)

PASO 3: Solucionar el problema del logo
----------------------------------------
php tests/fix_logo_problema.php

Este script convierte el logo a formato compatible y lo guarda como:
- imagenes/image_fixed.jpg
- ImpresionTermica/geek_fixed.png

PASO 4: Reemplazar el logo
---------------------------
# Backup del original
cp imagenes/image.jpg imagenes/image.jpg.backup

# Usar el logo arreglado
cp imagenes/image_fixed.jpg imagenes/image.jpg

PASO 5: Verificar que funciona
--------------------------------
php tests/test_imprimir_logo.php

Debe mostrar dimensiones correctas (no 0x0) y funcionar.

PASO 6 (Si falta GD): Instalar dependencias
---------------------------------------------
sudo bash scripts/instalar_gd_linux.sh

Esto instala GD y todas las dependencias necesarias.
