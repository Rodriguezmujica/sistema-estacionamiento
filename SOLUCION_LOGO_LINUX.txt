════════════════════════════════════════════════════════════════
  🔧 SOLUCIÓN RÁPIDA: Logo no aparece en Linux Mint
════════════════════════════════════════════════════════════════

PROBLEMA:
---------
El logo no aparece en los tickets impresos en Linux Mint.

════════════════════════════════════════════════════════════════
  PASO 1: DIAGNÓSTICO
════════════════════════════════════════════════════════════════

Ejecuta el script de diagnóstico para ver QUÉ falta:

  cd /var/www/html/sistemaEstacionamiento
  php tests/test_gd_logo.php

Este script te mostrará:
  ✅ Qué está instalado
  ❌ Qué falta
  💡 Cómo solucionarlo

════════════════════════════════════════════════════════════════
  PASO 2: INSTALAR GD
════════════════════════════════════════════════════════════════

OPCIÓN A: Automático (Recomendado)
-----------------------------------
  sudo bash scripts/instalar_gd_linux.sh

OPCIÓN B: Manual
-----------------
  sudo apt-get update
  sudo apt-get install php-gd libpng-dev libjpeg-dev libgd-dev
  sudo systemctl restart apache2

════════════════════════════════════════════════════════════════
  PASO 3: VERIFICAR
════════════════════════════════════════════════════════════════

Verificar que funcionó:

  php tests/test_gd_logo.php

Debe mostrar: ✅ TODO ESTÁ CORRECTO

════════════════════════════════════════════════════════════════
  PASO 4: PROBAR IMPRESIÓN DEL LOGO
════════════════════════════════════════════════════════════════

Probar que el logo se carga correctamente:

  php tests/test_imprimir_logo.php

Si esto funciona, el logo debería aparecer en los tickets.

════════════════════════════════════════════════════════════════
  COMANDOS ÚTILES
════════════════════════════════════════════════════════════════

# Ver si GD está instalado
php -m | grep gd

# Ver información de GD
php -r "print_r(gd_info());"

# Verificar PNG Support
php -r "echo gd_info()['PNG Support'] ? 'OK' : 'FALTA';"

# Ver logs de errores de Apache
sudo tail -f /var/log/apache2/error.log

# Ver permisos de archivos de logo
ls -la imagenes/image.jpg
ls -la ImpresionTermica/geek.png

════════════════════════════════════════════════════════════════
  SOLUCIÓN DE PROBLEMAS
════════════════════════════════════════════════════════════════

Si después de instalar GD el logo sigue sin aparecer:

1. Revisa los logs durante una impresión:
   sudo tail -f /var/log/apache2/error.log
   (Luego intenta imprimir un ticket)

2. Verifica que el archivo existe:
   ls -la imagenes/image.jpg

3. Verifica permisos (debe ser legible):
   chmod 644 imagenes/image.jpg

4. Prueba el logo directamente:
   php tests/test_imprimir_logo.php

════════════════════════════════════════════════════════════════

Para más detalles, ver los archivos:
  - tests/test_gd_logo.php (diagnóstico completo)
  - tests/test_imprimir_logo.php (prueba directa)
