  📋 PASOS EN WINDOWS (Para copiar)
════════════════════════════════════════════════════════════════

1. Abre: C:\xampp\htdocs\sistemaEstacionamiento\

2. Crea en el USB:
   USB:\sistemaEstacionamiento\

3. Copia estas carpetas completas:
   - tests\        → USB:\sistemaEstacionamiento\tests\
   - scripts\      → USB:\sistemaEstacionamiento\scripts\

4. O copia archivo por archivo:

   DE: tests\test_gd_logo.php
   A:  USB:\sistemaEstacionamiento\tests\test_gd_logo.php

   DE: tests\fix_logo_problema.php
   A:  USB:\sistemaEstacionamiento\tests\fix_logo_problema.php

   DE: tests\test_imprimir_logo.php
   A:  USB:\sistemaEstacionamiento\tests\test_imprimir_logo.php

   DE: tests\crear_logo_simple.php
   A:  USB:\sistemaEstacionamiento\tests\crear_logo_simple.php

   DE: scripts\instalar_gd_linux.sh
   A:  USB:\sistemaEstacionamiento\scripts\instalar_gd_linux.sh

════════════════════════════════════════════════════════════════
  🔧 COMANDOS EN LINUX MINT (Después de copiar del USB)
════════════════════════════════════════════════════════════════

# 1. Copiar archivos del USB al servidor
sudo cp -r /media/[usuario]/[USB]/sistemaEstacionamiento/tests \
          /var/www/html/sistemaEstacionamiento/

sudo cp -r /media/[usuario]/[USB]/sistemaEstacionamiento/scripts \
          /var/www/html/sistemaEstacionamiento/

# 2. Dar permisos
sudo chmod +x /var/www/html/sistemaEstacionamiento/scripts/instalar_gd_linux.sh

# 3. Ir al directorio
cd /var/www/html/sistemaEstacionamiento

# 4. EJECUTAR EN ESTE ORDEN:

# Paso 1: Ver qué falta
php tests/test_gd_logo.php

# Paso 2: Arreglar el logo (LO MÁS IMPORTANTE)
php tests/fix_logo_problema.php

# Paso 3: Reemplazar logo
cp imagenes/image.jpg imagenes/image.jpg.backup
cp imagenes/image_fixed.jpg imagenes/image.jpg

# Paso 4: Probar
php tests/test_imprimir_logo.php

# Paso 5: Si falta GD (ejecutar como sudo)
sudo bash scripts/instalar_gd_linux.sh
